# Blackcoffer Visualization Dashboard

## Tech Stack
- React.js
- Node.js
- Express.js
- MongoDB
- Chart.js
- Tailwind CSS

## Features
- Interactive Dashboard
- MongoDB Integration
- REST API
- Country Filter
- Topic Filter
- Region Filter
- Sector Filter
- Source Filter
- PESTLE Filter
- City Filter
- Year Filter
- Bar Chart
- Pie Chart
- Line Chart
- Responsive UI

## Installation

### Backend
cd backend
npm install
node server.js

### Frontend
cd frontend
npm install
npm run dev
